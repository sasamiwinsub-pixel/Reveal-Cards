# 最初からクリアまでのE2E

このフォルダーのテストには全ステージの解答を含みます。

## 実行

```sh
pnpm install --frozen-lockfile
pnpm exec playwright install chromium
pnpm test:e2e
```

デスクトップ幅1280pxとモバイル幅375pxのChromiumで、同じシナリオを順番に実行します。
FinalでA→JとJ→Aの両方の生成順を検証するため、計4ケースです。生成直後の画像URLと画像の読み込みを確認し、それぞれスクリーンショットも保存します。
カード操作はドラッグではなく、カードを選択して配置場所をクリックする方式です。

```sh
pnpm test:e2e:desktop
pnpm test:e2e:mobile
pnpm test:e2e:report
```

標準では http://127.0.0.1:3000 の開発サーバーを使用します。起動済みなら再利用し、未起動ならPlaywrightが起動・終了します。
別ポートや本番ビルドを検証する場合は、起動済みサーバーのURLを `E2E_BASE_URL` に指定してください。この場合、テストはサーバーを起動・停止しません。

PowerShellでの例:

```powershell
$env:E2E_BASE_URL = "http://127.0.0.1:3100"
pnpm test:e2e
```

## 検証内容

- オープニング、説明、タイトル、ルール・仕様・会場MAPのチュートリアル。
- 1stStageの意図された初回敗北、交換解放、全3戦の勝利。
- 1stStage第2ゲームで配置確認前と確定直後にリロードして続行。
- 2ndStage全4戦。スキャン解放、紙の問題、現物スキャン、紙の9と10の交換。
- Q2枚の現物スキャンでAを生成し、交換して2ゲームに勝利。
- 3rdStage全4戦。0・A・Jの生成、コピーペースト解放とルール変更、ポーカー勝利。
- Final第一段階の2交換とタイミング変更、監視による意図された敗北。
- Finalのハイ＆ロー宣言時へのタイミング変更、開始時の発言、敗北・再挑戦、誤ったペーストのやり直し。
- 再挑戦による第二段階への移行、能力回数とブラックジャック宣言時の引き継ぎ。
- Final第二段階の3つのペースト変更、A・J・Kの生成、2交換、3ゲーム勝利。
- 実際の「クリア画面へ」ボタンからクリア画面へ遷移し、勝利文言を確認。
- 全行程で未処理のクライアント例外がないこと。

初期状態はPlaywrightの新規ブラウザーコンテキストです。sessionStorageやReactの状態の注入、途中の対戦URLへの直接移動、ネットワーク応答のモックは行いません。

## 結果

`playwright-report/` にHTMLレポート、`test-results/` に実行結果を出力します。
失敗時はスクリーンショット・動画・トレースを保存し、レポートのステップ名から停止した対戦を確認できます。
成功時も、最終クリア画面を各プロジェクトの `game-clear.png` に保存します。
両出力フォルダーはGit管理対象外です。
